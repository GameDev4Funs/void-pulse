# VOID PULSE · 驾驶员手册

[返回游戏首页](../README.md) · [在线试玩](https://gamedev4funs.github.io/void-pulse/)

详细操作、构筑配方和战场规则，供想进一步研究打法的驾驶员查阅。

## 操作

| 按键 | 功能 |
| --- | --- |
| WASD / 方向键 | 移动 |
| F / 鼠标 | 切换自动瞄准 / 鼠标瞄准（默认自动，始终自动开火） |
| SPACE / SHIFT | 冲刺（带无敌帧，可穿敌） |
| Q / 鼠标右键 | 超载冲击波（能量满时清场） |
| E | 湮灭协议（碎片充能的终极大招） |
| ESC / P | 打开菜单：单机暂停，联机可设置/离房但世界继续 |
| B | 查看构筑、全部进化配方与下级数值 |
| M | 静音 |
| R | 选卡时重抽（每局 2 次）；结算界面快速重开 |
| 右下角设置 | 音乐 / 音效音量、自动瞄准、减少震屏与闪光、画质 |

触屏设备自动启用虚拟摇杆、自动瞄准及冲刺 / Q / E 三个技能按钮。

## 战场与构筑

- **四星球出击**：主菜单选星球；联机由房主在大厅选择，结算后返回大厅可换星球，新一局重置构筑。客机自动同步地形、环境事件和数值。不会在战斗中途更换规则。
  - 能源母港：均衡混合虫潮、单发射手与周期放电。
  - 霜环星：移速 +12%、冲刺冷却 −20%；疾行者和猎手为主，冰锥射手打出三向弹幕，寒潮强减速。
  - 熔核星：武器伤害 +18%、生命上限 +10；自爆蜂与坦克为主，射手发射重型双弹，自爆蜂引爆后射出环形爆片（击杀触发的友方连锁不产生敌弹）。
  - 孢林星：每秒修复 0.6 HP、拾取范围 +25%；分裂体和织网者为主，射手与 Boss 铺孢子区，圈内减速且持续掉血。
- **战斗准星**：桌面战斗画布使用高对比瞄准星，菜单、暂停和设置恢复普通鼠标；触屏保持原有摇杆操作。
- 出生于目标圈外；向前移动拾取第一批绿色碎片，体验首次选卡，再前往反应堆。
- 击杀掉落**能量碎片**，拾取升级，每级从 3 张强化卡中选 1 张。LV20 后每级需求线性增加，避免长局升级成本继续二次增长。
- **反应堆争夺**：24 秒首次上线，之后每 85 秒开启 38 秒的夺取窗口。进入中央金色光环，累计坚守 7 秒；多人协作最多加速 50%，圈内敌人会令充能降至 30%，离开则缓慢回退。完成后每位存活队员修复 18 HP，全队获得 25 超载能量、18 秒射速 +25%，团队得分 +400。
- **战术小地图**：显示队友、敌人、掩体、补给、中央目标和放电带。目标面板提供距离、倒计时、充能进度和虫潮阶段。
- **升级重抽**：每局 2 次，优先避开上一组卡；仍保留必出进化卡。联机选卡以小面板展示，世界继续运行，选定后获得 0.8 秒保护。
- **流派羁绊（核心 Combo）**：每张卡属于燃烧 🔥 / 雷霆 ⚡ / 虚空 🌑 三条流派之一，
  同流派投入等级越多，刷到该流派卡的概率越高；投入 4 / 8 / 13 级时觉醒阶层能力：
  - 🔥 燃烧：**余烬**（伤害+12%）→ **爆燃**（击杀爆炸）→ **焚天**（武器与流派伤害附加点燃，Q/E 除外）
  - ⚡ 雷霆：**迅捷**（射速+12%）→ **落雷**（击杀 25% 天降神雷）→ **雷神**（每 5s 轰击最密敌群）
  - 🌑 虚空：**韧性**（生命+20 护甲+1）→ **反噬**（受伤释放新星）→ **吞噬**（每 8s 处决周围残血）
- **武器进化**：武器满 5 级 + 对应被动 → 必出金色进化卡：
  - 脉冲枪 + 超频模块 → **湮灭射线**（无限穿透的重型光束）
  - 轨道刃 + 离子推进器 → **风暴剑域**（8 刃环绕 + 全方位飞刃风暴）
  - 追踪导弹 + 增幅核心 → **蜂群蜂巢**（8 枚子母导弹）
  - 特斯拉电弧 + 弱点扫描仪 → **天罚雷狱**（12 链闪电 + 持续雷狱）
  - 新星爆发 + 纳米装甲层 → **超新星坍缩**（引力拉扯 + 爆发 + 护盾）
- **连锁击杀**：连杀得分倍率最高 3 倍，每 15 连锁触发金色冲击波。
- **超载 [Q]**：近身解围、消弹与短暂无敌；伤害为 85 + 目标最大生命的 8%。
- **湮灭协议 [E]**：全场消弹，对普通敌人造成 500 伤害，对 Boss 造成最大生命的 25%；拾取碎片充能，越用充能越慢。
- Q/E 不附加点燃，也不触发额外击杀爆炸、落雷或连锁冲击伤害；普通技能击杀按 25% 返能且每次最多返还 25 Q。Boss 是额外奖励：每位存活队员获得 100 Q / 40 E。
- 敌人随时间渐进解锁：疾行者 25 秒、分裂体 55 秒、射手 78 秒、自爆蜂 96 秒、坦克 125 秒、猎手 148 秒、织网者 175 秒；150 秒后逐步加入精英变体。
- **威胁预算**：36 秒一轮推进 / 高潮 / 喘息；重型和远程敌人消耗更多预算。预警圈满时延后刷怪，玩家进入圈内时取消生成。
- **反绕圈**：少量移动前方截杀；72 秒首次包围，此后每 84 秒一次。
- 180 秒首次出现 **VOID OVERLORD**，之后每 165 秒一只（MK.II 起追加螺旋弹幕）；冲锋先锁定方向并蓄力 0.75 秒；定期空投补给舱。
- 结算显示最后伤害来源、最终构筑与本人的实际伤害贡献。最高纪录按星球、单人/开局队伍人数、任务/无尽分别保存（localStorage）；客机独立计算本机新纪录。旧版混合纪录保留在原存储键中，不混入新分类。
