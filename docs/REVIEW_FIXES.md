## 同时完成的体验与整合修复

- 世界设定统一为远程驾驶无人战机，夺回能源设施、达到撤离条件；战机击毁后可修复，剧情措辞与无尽选择一致。
- 4m 内靠近倒地队友可令修复速度翻倍；HUD、小地图与倒地面板显示救援信息。
- 孢子/蛛网危险区使用橙/粉色、双边界与锯齿标记，区别于绿色经验；降低全局辉光强度。
- 设置提供可保存画质；减少动态效果选项同时抑制 CSS 动画。触屏显示对应操作提示。
- 结算提供最终构筑、最后伤害来源和本人实际伤害贡献。
- 联机胜利后的继续无尽/返回大厅由房主统一推进；客机可离房，不能独自重置仍在进行的队伍。
- 结算停留后恢复有心跳宽限，保留真实倒地/暂离；房主后台恢复同样避免误判全队失联。
- 护盾抵挡攻击后提供受击无敌，避免同帧下一次碰撞穿透护盾。
