# VOID PULSE — 霓虹深渊幸存者

一款纯前端 3D 竞技场生存游戏（survivors-like），支持**单机**与**局域网 2-4 人组队**。
作为远程驾驶员，操纵无人战机夺回被虫群侵占的能源设施。完成 3 次反应堆修复并坚守 10 分钟，即可撤离；任务完成后可保留构筑，继续无尽挑战。

**▶ [在线试玩](https://awsomekde.github.io/void-pulse/)** — 静态托管，仅单机模式；联机需按下方说明本地运行中继服务。

## 运行

需要通过 HTTP 访问（ES Module 限制，双击 html 无法运行）：

```bash
# 方式一：双击 start.command（macOS，自动起本地服务并打开浏览器）
# 方式二：命令行（静态页面和联机中继共用同一端口）
cd 本目录 && npm start
# 然后浏览器打开 http://localhost:8123
```

无需联网，Three.js 已本地打包（`vendor/three`），Chrome / Edge / Safari 现代版本均可。
低配机器可在设置中选择低特效画质（关闭辉光、降低渲染分辨率，自动保存），也可用 `http://localhost:8123/?lowfx=1` 强制以低特效启动。

## 局域网联机（2-4 人）

1. 房主运行 `npm start`（页面与联机中继同源，不再需要单独开放 8124 端口）。
2. 所有人用浏览器打开 `http://<房主IP>:8123` → **组队联机**：
   - 房主点**创建房间** → 自动生成房名（如 `NEBULA-42`）+ 4 位密码，点击可复制；
   - 队友输入房名+密码 → **加入房间** → 大厅集结 → 房主开战。
3. 联机规则：
   - 每房最多 **4 人**；**无队友伤害**（架构上不存在 PP 伤害）；
   - 场地扩大至 **160×160 单元**，包含八个战术掩体、外围能源站和货箱装饰；
   - 每个星球有独立的环境事件时间表；能源母港 75 秒后首次放电、每 90 秒一轮。所有事件先预警 5 秒、危险持续 9 秒；熔核星隔次喷发穿过中央目标；
   - 敌人按推进/高潮/喘息波次生成，并按玩家轮转分配压力，出生点会避开玩家、墙体和掩体；
   - **团队共享经验/等级**，但每人独立选卡、独立构筑流派；
   - 战机被击倒后 10 秒修复完成（半血）；存活队友靠近 4m 内可让修复速度翻倍，**团灭**时任务失败；
   - 房主切后台时全队暂停；客机暂离或心跳中断超过 3 秒会被移出存活/拾取/占点判定，回来后以倒地状态等待修复；
   - 任务胜利后由房主选择全队继续无尽或返回大厅，队员也可自行离开房间；
   - 架构：房主权威模拟敌人/掉落，客机本地模拟战机与武器，伤害事件上报；
   - 部署到 HTTPS 环境时会自动使用同源 `wss://.../ws`，避免混合内容和额外端口不可达。

## 操作

| 按键 | 功能 |
| --- | --- |
| WASD / 方向键 | 移动 |
| F / 鼠标 | 切换自动瞄准 / 鼠标瞄准（默认自动，始终自动开火） |
| SPACE / SHIFT | 冲刺（带无敌帧，可穿敌） |
| Q / 鼠标右键 | 超载冲击波（能量满时清场） |
| E | 湮灭协议（碎片充能的终极大招） |
| ESC / P | 打开菜单：单机暂停，联机可设置/离房但世界继续 |
| B | 查看构筑、全部进化配方与下级数值 |
| M | 静音 |
| R | 选卡时重抽（每局 2 次）；结算界面快速重开 |
| 右下角设置 | 音乐 / 音效音量、自动瞄准、减少震屏与闪光、画质 |

触屏设备自动启用虚拟摇杆、自动瞄准及冲刺 / Q / E 三个技能按钮。

## 玩法

- **四星球出击**：主菜单选星球；联机由房主在大厅选择，结算后返回大厅可换星球，新一局重置构筑。客机自动同步地形、环境事件和数值。不会在战斗中途更换规则。
  - 能源母港：均衡混合虫潮、单发射手与周期放电。
  - 霜环星：移速 +12%、冲刺冷却 −20%；疾行者和猎手为主，冰锥射手打出三向弹幕，寒潮强减速。
  - 熔核星：武器伤害 +18%、生命上限 +10；自爆蜂与坦克为主，射手发射重型双弹，自爆蜂引爆后射出环形爆片（击杀触发的友方连锁不产生敌弹）。
  - 孢林星：每秒修复 0.6 HP、拾取范围 +25%；分裂体和织网者为主，射手与 Boss 铺孢子区，圈内减速且持续掉血。
- **战斗准星**：桌面战斗画布使用高对比瞄准星，菜单、暂停和设置恢复普通鼠标；触屏保持原有摇杆操作。
- 出生于目标圈外；向前移动拾取第一批绿色碎片，体验首次选卡，再前往反应堆。
- 击杀掉落**能量碎片**，拾取升级，每级从 3 张强化卡中选 1 张。LV20 后每级需求线性增加，避免长局升级成本继续二次增长。
- **反应堆争夺**：24 秒首次上线，之后每 85 秒开启 38 秒的夺取窗口。进入中央金色光环，累计坚守 7 秒；多人协作最多加速 50%，圈内敌人会令充能降至 30%，离开则缓慢回退。完成后每位存活队员修复 18 HP，全队获得 25 超载能量、18 秒射速 +25%，团队得分 +400。
- **战术小地图**：显示队友、敌人、掩体、补给、中央目标和放电带。目标面板提供距离、倒计时、充能进度和虫潮阶段。
- **升级重抽**：每局 2 次，优先避开上一组卡；仍保留必出进化卡。联机选卡以小面板展示，世界继续运行，选定后获得 0.8 秒保护。
- **流派羁绊（核心 Combo）**：每张卡属于燃烧 🔥 / 雷霆 ⚡ / 虚空 🌑 三条流派之一，
  同流派投入等级越多，刷到该流派卡的概率越高；投入 4 / 8 / 13 级时觉醒阶层能力：
  - 🔥 燃烧：**余烬**（伤害+12%）→ **爆燃**（击杀爆炸）→ **焚天**（武器与流派伤害附加点燃，Q/E 除外）
  - ⚡ 雷霆：**迅捷**（射速+12%）→ **落雷**（击杀 25% 天降神雷）→ **雷神**（每 5s 轰击最密敌群）
  - 🌑 虚空：**韧性**（生命+20 护甲+1）→ **反噬**（受伤释放新星）→ **吞噬**（每 8s 处决周围残血）
- **武器进化**：武器满 5 级 + 对应被动 → 必出金色进化卡：
  - 脉冲枪 + 超频模块 → **湮灭射线**（无限穿透的重型光束）
  - 轨道刃 + 离子推进器 → **风暴剑域**（8 刃环绕 + 全方位飞刃风暴）
  - 追踪导弹 + 增幅核心 → **蜂群蜂巢**（8 枚子母导弹）
  - 特斯拉电弧 + 弱点扫描仪 → **天罚雷狱**（12 链闪电 + 持续雷狱）
  - 新星爆发 + 纳米装甲层 → **超新星坍缩**（引力拉扯 + 爆发 + 护盾）
- **连锁击杀**：连杀得分倍率最高 3 倍，每 15 连锁触发金色冲击波。
- **超载 [Q]**：近身解围、消弹与短暂无敌；伤害为 85 + 目标最大生命的 8%。
- **湮灭协议 [E]**：全场消弹，对普通敌人造成 500 伤害，对 Boss 造成最大生命的 25%；拾取碎片充能，越用充能越慢。
- Q/E 不附加点燃，也不触发额外击杀爆炸、落雷或连锁冲击伤害；普通技能击杀按 25% 返能且每次最多返还 25 Q。Boss 是额外奖励：每位存活队员获得 100 Q / 40 E。
- 敌人随时间渐进解锁：疾行者 25 秒、分裂体 55 秒、射手 78 秒、自爆蜂 96 秒、坦克 125 秒、猎手 148 秒、织网者 175 秒；150 秒后逐步加入精英变体。
- **威胁预算**：36 秒一轮推进 / 高潮 / 喘息；重型和远程敌人消耗更多预算。预警圈满时延后刷怪，玩家进入圈内时取消生成。
- **反绕圈**：少量移动前方截杀；72 秒首次包围，此后每 84 秒一次。
- 180 秒首次出现 **VOID OVERLORD**，之后每 165 秒一只（MK.II 起追加螺旋弹幕）；冲锋先锁定方向并蓄力 0.75 秒；定期空投补给舱。
- 结算显示最后伤害来源、最终构筑与本人的实际伤害贡献。最高纪录按星球、单人/开局队伍人数、任务/无尽分别保存（localStorage）；客机独立计算本机新纪录。旧版混合纪录保留在原存储键中，不混入新分类。

## 技术要点

- Three.js r185（本地 vendor，importmap 引入），UnrealBloom 辉光后期（可 lowfx 关闭）。
- 场景使用三张生成式美术贴图（合金地板 / 设施装甲 / 反应堆平台），运行时约 1 MB；原图和提示词见 [贴图说明](assets/textures/README.md)。音效与 BGM 由 WebAudio 实时合成。
- 玩家/队友、九类普通敌人和 Boss 使用透明角色原画与共享图集，保留队友色环、精英标记和战斗预警；原图与提示词见 [角色美术](assets/actors/README.md)。
- 联机：纯标准库 Python WebSocket 房间中继 + 房主权威模拟 + 客机插值/短时预测（10Hz 世界快照、20Hz 玩家位置 + 事件流）。
- 对象池（敌人 / 子弹 / 粒子 / 碎块 / 飘字）+ 空间哈希与弹道扫掠碰撞；模拟子步最大 1/60 秒，每个渲染帧最多追赶 250ms，后台返回丢弃隐藏时长，HUD 按真实渲染间隔统计 FPS。小地图 10Hz 刷新，地面导引线实例化渲染。
- 首屏使用约 13KB 星球缩略图，选中星球后才加载完整地表；静态服务器仅提供运行必需资源，拒绝隐藏目录、脚本、CSV、原画源目录和目录浏览。
- 打击感：击杀顿帧、受击挤压形变、甲壳碎块迸溅、击杀冲击击退、屏幕震动、慢动作。

## 开发自测

```bash
node scripts/smoke.mjs [url]   # 状态机冒烟（需本地 Chrome）
node scripts/soak.mjs          # 高压浸泡（全进化武器 + 全敌人 + 包围事件）
node scripts/evo_check.mjs     # 进化卡出现逻辑
node scripts/route_check.mjs   # 流派觉醒 + 湮灭协议
node scripts/mp_test.mjs       # 联机端到端（建房/同步/伤害/重生/团灭/满员）
node scripts/mp_perf.mjs       # 四人联机高负载性能回归
node scripts/reactor_test.mjs  # 目标时序 / 干扰 / 衰减 / 奖励 / 重置
node scripts/texture_test.mjs [url] # 贴图回归；不传 URL 时自启 8135 测试服务
node scripts/actor_art_test.mjs [url] # 角色图集 / 朝向 / 闪光 / 回退 / 释放；默认自启 8136
```

新机制使用联机协议 v6；组队前所有玩家需刷新到同一版本，旧版客户端无法加入新版房间。

`npm run test:planets` 验证四星球地表、敌群/弹幕、环境危险、属性重置、准星、键盘/触屏、GPU 贴图回收和双浏览器跨星球联机；可传现有服务 URL 进行部署后验收。
`node scripts/mp_perf.mjs <URL> <planet>` 验证指定星球的四人默认画质压力表现；planet 为 `station` / `cryo` / `volcanic` / `mycelium`，默认 `station`。
三张新地表由内置 imagegen 生成，原始素材和完整提示词见 [assets/planets/README.md](assets/planets/README.md)。

新增审查回归：`npm run test:combat`、`test:game`、`test:ui`、`test:mp:rules`、`test:server`。Node 测试需 Node 24+；浏览器用本机 Chrome，脚本自行关闭临时服务和浏览器。完整修复对应关系及验证边界见 [审查修复记录](docs/REVIEW_FIXES.md)。
